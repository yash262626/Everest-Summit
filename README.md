# Everest — The Roof of the World

A cinematic **scroll-driven journey to the summit of Mount Everest (8,849 m)**. Single file, no build step.

## Run
Open `index.html` in a browser, or host it on Netlify / GitHub Pages as-is. Best on desktop; works on mobile.

## Sections
Hero → Sagarmatha/Chomolungma/Everest intro → a century on the mountain → the South Col route → interactive route atlas → the climb (altitude counter) → summit 8,849 → finale.

## Tech
GSAP + ScrollTrigger for scroll animation, Lenis for smooth scrolling, Canvas/WebGL visuals, WebAudio for sound. Loaded inline in one `index.html`.
